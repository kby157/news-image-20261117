# news-image-20261117

Newspaper front page summing up Tuesday 17 November 2026 world news in one image for the [make.fun](https://make.fun/bounty/news-image-20261117) bounty.

## Run

```sh
python3 main.py
```

Copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`). No network; two runs write the same bytes.

Rebuild the art (optional):

```sh
python3 generate_entry.py
```
